## 📌 Proje Hakkında

`Space_Clear`, Windows üzerinde kullanılabilecek disk alanı temizleme yaklaşımını ve sistem bakım işlemlerini öğrenmek için hazırlanmış bir projedir.

## ✨ Amaç

- Gereksiz dosyaların temizlenmesi yaklaşımını incelemek
- Disk alanı yönetimini öğrenmek
- Windows bakım araçlarıyla çalışmak
- Masaüstü yardımcı uygulaması geliştirme pratiği yapmak

## 🧰 Teknoloji Kartları

| Teknoloji | Rol |
|---|---|
| 💻 **C# / .NET** | Masaüstü uygulaması |
| 🪟 **Windows** | Hedef platform |
| 💾 **File System** | Dosya ve disk işlemleri |

## 🚀 Kurulum

```bash
git clone https://github.com/ebubekirbastama/Space_Clear.git
```

Solution dosyasını Visual Studio ile açarak derleyin.

## ⚠️ Güvenlik

Disk temizleme uygulamalarında yanlış dosyanın silinmesi veri kaybına yol açabilir. Kritik sistemlerde çalıştırmadan önce dosya yollarını ve silme kriterlerini mutlaka inceleyin.

## 📌 Proje Durumu

Legacy/öğrenme amaçlı bir çalışma olarak değerlendirilmelidir. Modern bir sürümde dry-run modu, silinecek dosyaların önizlemesi, geri alma/geri dönüşüm kutusu desteği, loglama ve güvenli klasör beyaz listesi eklenmesi önerilir.
